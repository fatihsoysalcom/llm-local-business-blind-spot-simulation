# LLM Local Business Blind Spot Simulation

This example simulates why Large Language Models (LLMs) often fail to provide accurate and up-to-date local business recommendations. It compares a simulated LLM, which is prone to hallucination and outdated information, with a simple, accurate local database for specific queries. This highlights the 'blind spot' LLMs have regarding dynamic, hyper-local data.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal using `python main.py`.
